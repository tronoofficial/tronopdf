How to Password Protect PDF Files

1
Upload your PDF — Click "Select PDF file" button or drag & drop your document. The tool accepts any PDF file you want to protect with a password.
2
Set password — Enter a strong password (minimum 6 characters). This will be required to open the PDF. Optionally set a separate owner password for full control.
3
Configure permissions — Click "Advanced options" to control what users can do: allow or block printing, copying, editing and annotating. Set permissions based on your security needs.
4
Protect and download — Click "Protect PDF" button. The tool encrypts your file with AES-256, verifies the protection works, then provides the secured PDF for download. All processing happens in your browser using MuPDF - nothing is uploaded.
