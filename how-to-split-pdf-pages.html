Page Range Format Guide

TronoPDF uses a simple and flexible format for selecting pages:

  • 5 → extract only page 5
  • 1-3 → extract pages 1, 2 and 3
  • 1-3, 5, 7-10 → extract pages 1, 2, 3, 5, 7, 8, 9 and 10
  • 1, 3, 5-8 → extract page 1, page 3, and pages 5 to 8

💡 Pro tip: You can enter multiple ranges separated by commas. Each range becomes a separate PDF file in the output.

Tips For Best Results

  • Check page numbers first — open the PDF to confirm which pages you need.
  • Keep the original file — splitting creates new files; your original stays intact.
  • Compress after splitting — if the extracted PDF is too large, use Compress PDF.
  • Merge back if needed — use Merge PDF to recombine split files.

⚠️ Always verify the output file before deleting or replacing the original, especially for important documents like contracts or certificates.

Split PDF vs Extract Pages — What's The Difference?

  • Split PDF = Divide a PDF into multiple new PDF files based on page ranges
  • Extract pages = Same as splitting — these terms are often used interchangeably
  • Remove pages = Keep everything except specific pages (the opposite of extract)
