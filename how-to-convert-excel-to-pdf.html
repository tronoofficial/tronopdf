What Gets Preserved

  • Tables and data — All cell values and structure
  • Formatting — Colors, fonts, borders
  • Charts and graphs — Visual representations
  • Multiple sheets — Each sheet becomes a PDF page or section
  • Formulas (as values) — Results are preserved, not formulas

Tips For Best Results

  • Set print area — Define what to include in the PDF
  • Choose orientation — Landscape for wide tables
  • Check page breaks — Avoid awkward splits
  • Hide unnecessary columns — Before converting
  • Keep original Excel — For future formula updates
  • Compress if needed — Use Compress PDF for smaller file
