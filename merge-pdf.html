  • Business reports — Combine multiple chapters, appendices, and supporting documents

Merge PDF for Job Applications (Indian Portals)

Most Indian government job portals (SSC, UPSC, IBPS, RRB) require you to upload all documents in a single PDF under specific size limits. Here's the complete workflow:

Step 1: Prepare Your Documents

  • Scan all certificates, marksheets, and ID proofs to PDF format
  • Ensure each document is clear and readable
  • Convert images to PDF using our JPG to PDF tool if needed

Step 2: Merge in Correct Order

  • Typical order: Application form → Resume → Educational certificates → ID proof → Category certificate
  • Drag and drop PDF cards to arrange in the required sequence
  • First PDF in the list becomes the first pages of the merged document

Step 3: Compress to Meet Size Limits

  • Most portals require 100KB to 500KB file size
  • After merging, use our Compress PDF tool to reduce size
  • Use Target Size mode to hit exact KB requirement (e.g., 200KB)
💡 Pro tip: Always keep the original merged (uncompressed) file as backup. If the compressed version loses too much quality, you can re-compress with different settings.

Merge vs Organize vs Split — Which Tool to Use?

📑 Merge PDF

Use when: You have multiple separate PDF files and want to combine them into one document.

Example: Merge resume.pdf + certificate1.pdf + certificate2.pdf into application.pdf

📂 Organize PDF

Use when: You have one PDF and want to reorder, delete, or insert pages within it.

Example: Move page 5 to position 2, delete blank page 10, insert new page after page 3

✂️ Split PDF

Use when: You have one PDF and want to extract specific pages into separate files.

Example: Extract pages 1-5 into part1.pdf and pages 6-10 into part2.pdf

Tips for Best Merge Results

✅ Do This:

  • Plan your order first — Write down the sequence before dragging files
  • Use consistent page sizes — Merge A4 with A4, not A4 with Letter size
  • Check orientation — Rotate sideways pages with Rotate PDF before merging
  • Test the merged file — Open and review all pages before sharing
  • Keep originals — Save the merged file separately, don't overwrite source PDFs
  • Compress after merging — Merged files are often large; compress for easier sharing

❌ Avoid This:

  • Don't merge 100+ files at once — Browser may slow down; merge in batches instead
  • Don't mix protected and unprotected PDFs — Unlock protected files first
  • Don't forget to verify order — Double-check sequence before clicking merge
  • Don't skip compression — Large merged files are hard to email or upload

Advanced Merge Techniques

Batch Merging for Large Projects

For projects with 50+ PDF files:

  • Merge files in groups of 10-15
  • Then merge the resulting files together
  • This approach is faster and more reliable than merging all at once

Merging with Different Page Sizes

When merging PDFs with different page sizes (A4, Letter, Legal):

  • The merged PDF will have mixed page sizes
  • Consider standardizing sizes before merging using Crop PDF
  • Or accept mixed sizes if that's intentional for your document

Handling Password-Protected PDFs

If some PDFs are password-protected:

  • Use Unlock PDF to remove protection first (you must know the password)
  • Then merge the unlocked files normally
  • After merging, you can re-protect the combined file if needed
