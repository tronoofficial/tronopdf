What Gets Highlighted

  • Added text — New content in the modified version
  • Removed text — Content deleted from the original
  • Modified text — Changed wording or values
  • Moved content — Relocated paragraphs or images
  • Percentage difference — Overall change metric

💡 Pro tip: For contracts, always review every highlighted change manually — automated comparison is a guide, not a legal verdict.

Tips For Best Results

  • Use text-based PDFs — Scanned PDFs compare less accurately
  • Same structure — Best results when versions have similar layout
  • Review manually — Verify critical changes yourself
  • Keep both versions — For records and reference
  • Note the percentage — Large differences may indicate wrong files

⚠️ For legally binding contract review, use comparison as a starting point but always read the final document in full.
